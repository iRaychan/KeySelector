KeyCHC V3.4.5 Standalone — Validation Results
Date: 2026-08-08

PASS — JavaScript syntax
- Extracted inline application JavaScript passes `node --check`.

PASS — Standalone access
- No KeySuite, Supabase, login, config.js, or user-approval dependency is required.

PASS — D1 selection logic
- Number-of-pumps-running-at-D1 control is removed.
- D1 Flow + Head is evaluated directly as a single-pump selection duty.

PASS — Parallel reference controls
- Six independent Display Settings controls exist: 1P, 2P, 3P, 4P, 5P, 6P.
- Parallel references do not alter the D1 model-selection duty.
- Enabled references are applied to Pump Curve, Efficiency, Power, and NPSH.
- Power references use total power for the enabled pump count.

PASS — Live curve speed
- A model selected at 50 Hz remains selected when the display/curve speed is changed.
- Pump, Efficiency, Power, and NPSH reference curves update from the live speed.
- Selected Pump header distinguishes `Selected @` speed from current `Curve` speed.

PASS — Summary control
- Matching Summary and PDF controls are present.
- Expanded Summary uses a downward triangle; collapsed Summary uses a right triangle.
- Collapsed Summary retains only Efficiency, Shaft Power, and NPSHr KPI cards.

PASS — Multiple duty points
- D1 remains the selection duty.
- D2–D6 remain optional reference/display points.
- Duty-point labels render as D1, D2, D3, etc.

PASS — System Curve / Orifice
- System Curve is capped at shut-off head or the maximum flow of the highest enabled parallel reference, whichever is reached first.
- Operating Point remains the 1P pump/system intersection.
- Orifice / After-Orifice remains a 1P analysis function.

PASS — Alternative ordering
- Alternative Selection remains ordered CHC model small → big.
- For the same base model, `-2` is listed before the standard model.

PASS — PDF curve layout
- PDF uses current live curve speed and current display settings.
- Enabled 1P–6P references are rendered in Pump, Efficiency, Power, and NPSH charts.
- Main Pump Curve uses the full chart row.
- SVG charts use width:100% with automatic height; fixed-height PDF curve boxes were removed to prevent squeezing/stretching.

PASS — CHC data preservation
- Embedded CHC model database and dimensional data remain preserved from the V3.4.4 base.
